# Train Grabber V2: 实时拾取式构筑

> 纯前端 2D 伪 3/4 斜俯视沙漠废土火车构筑小游戏，基于 **Phaser 3 + TypeScript + Vite + Phaser Matter Physics** 实现。

---

## 核心机制

- **实时拾取式构筑**：持续前进、无法停车的火车，在行进中通过大型机械抓钩截取世界中的武器、能源、车厢与奇特物品。
- **选择 → 构筑 → 新需求 → 新选择** 的需求链：
  - 抓炮塔 → 战力提升 → 电力需求增加 → 电池价值上升
  - 抓车厢 → 槽位扩充、载重上限提高 → 净重增加 → 油耗提高
  - 抓黄金 → 终点评分提高 → 负重上升 → 影响后续装车，需主动决断取舍
- **Opportunity Window 动态窗口**：按预设组（Group A ~ L）在 3.2~4.5 秒内呈现具有冲突价值的物品组合，并在远中近纵深分散排布。
- **1 秒超重/槽位决断窗口**：拉回超重或无空槽物品时悬停 1 秒，在此期间右键丢弃车上模块即可完成腾位换装。
- **Power & Load & Fuel 铁三角**：
  - 供电不足时炮塔降频并闪烁报警；
  - 负重超过 70%、85% 触发减速与额外油耗；
  - 燃料耗尽进入 12 秒熄火倒计时。
- **8 分钟完整战役与终点结算**：经历教程、土匪领地、燃料荒原、废弃贸易区、危险废土与终点冲刺，到站展示 `YOUR TRAIN` 列车全貌与评分。
- **完整 Telemetry 与 Seed 复现**：支持导出全量行为切片与时间线 JSON，支持相同种子 100% 确定性重开复现。

## 游戏操作

| 操作 | 作用 |
| :--- | :--- |
| **鼠标移动** | 瞄准机械抓钩 |
| **鼠标左键** | 发射机械抓钩 |
| **鼠标右键** | 取消抓钩 / 悬停列车模块时**直接主动丢弃** |
| **ESC** | 暂停 / 继续 |
| **F1** | 打开 / 关闭全局实时 Debug 面板 |
| **F2** | 随时导出当前局 Telemetry 数据 (JSON) |

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 编译构建
npm run build
```
